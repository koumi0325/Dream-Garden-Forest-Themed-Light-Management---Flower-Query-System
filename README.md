# 🌸 Dream Garden: Flower Query System

> 織夢花園 森系輕經營 - 花卉查詢系統

一個輕量級、獨立運作的花卉資料查詢系統，收錄381種精美花卉，提供即時搜尋與分級瀏覽功能。

## ✨ 特色功能

- 🔍 **即時搜尋** - 輸入花卉名稱即時過濾結果
- 🎨 **視覺化分級** - 五種等級以顏色標籤區分（閃、星、稀、優、普）
- 📱 **響應式設計** - 適配各種螢幕尺寸
- 🚀 **零依賴** - 單一HTML檔案，無需安裝或伺服器
- 💾 **離線可用** - 所有資料內嵌，可完全離線使用

## 🌺 花卉等級系統

| 等級 | 顏色 | 說明 |
|------|------|------|
| 閃 | 🔴 紅色 | 最稀有的頂級花卉 |
| 星 | 🟡 黃色 | 珍稀星級花卉 |
| 稀 | 🟣 紫色 | 稀有品種 |
| 優 | 🔵 藍色 | 優質花卉 |
| 普 | 🟢 綠色 | 普通品種 |

## 📊 資料統計

- **總計花卉**：381 種
- **資料欄位**：名稱、等級、評分、備註
- **檔案大小**：約 53KB

## 🚀 使用方式

1. 下載 `index.html` 檔案
2. 使用瀏覽器直接開啟（建議使用 Chrome、Firefox、Edge）
3. 在搜尋框輸入花卉名稱進行查詢
4. 瀏覽完整的花卉列表

```bash
# 或使用 Git 克隆
git clone [your-repository-url]
cd 花卉圖鑑
# 直接開啟 index.html
```

## 💻 技術特點

- **純前端技術**：HTML5 + CSS3 + Vanilla JavaScript
- **內嵌資料**：JSON 資料直接嵌入 HTML，避免 CORS 問題
- **無框架依賴**：不依賴任何外部函式庫
- **簡潔高效**：單一檔案設計，載入快速

## 🔧 自訂與擴展

由於採用單一 HTML 檔案設計，您可以輕鬆修改：

- **樣式調整**：修改 `<style>` 區塊中的 CSS
- **功能擴展**：在 `<script>` 區塊添加新功能
- **資料更新**：更新 `flowersData` 陣列中的花卉資料
